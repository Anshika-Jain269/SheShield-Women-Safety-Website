# SheShield – Women Safety Website

**SheShield** is a women safety awareness website designed to provide useful safety resources and emergency support features. It aims to help women access safety information, report incidents, and find assistance when needed.

## 🌐 Live Demo

[Visit SheShield](https://sheshield123.netlify.app/)

## ✨ Features

- **User Authentication:** Login functionality using Firebase.
- **Safety Resources:** Access useful information about women's safety and self-defense.
- **Emergency SOS:** An emergency alarm feature to alert people nearby.
- **Emergency Contacts:** Save important contacts such as parents, guardians, and mentors.
- **Anonymous Incident Reporting:** Submit incident details, including date, time, location, and other relevant information.
- **AI Chatbot:** An interactive chatbot that provides safety-related assistance.
- **Home Shelter Information:** Access shelter-related resources.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Firebase
- LocalStorage
- Map APIs

## 🎯 Project Objective

The main objective of SheShield is to create a digital platform that promotes women's safety awareness and provides easy access to emergency resources and support features.

1. Clone the repository:

   ```bash
   git clone https://github.com/Anshika-Jain269/SheShield-Women-Safety-Website.git
   ```

2. Navigate to the project folder:

   ```bash
   cd SheShield-Women-Safety-Website
   ```

3. Open `index.html` in your browser to run the website.
